绘图命令速查表

18 个，按用得多少排的
命令快捷键画出来是什么什么时候用它
LINEL一条直线段用得最多。画池体轮廓、管线、图框
PLINEPL连成一整条的多段线要整体偏移、算面积、改线宽时用。画工艺流程图管线、箭头
CIRCLEC圆圆形沉淀池、检查井、法兰、风机
ARCA圆弧弯头、池体圆角过渡、池底坡度线
RECTANGREC矩形（整体）设备基础、池体矩形平面、图框、标题栏
POLYGONPOL正多边形六角螺栓头、人孔、阀门手轮
ELLIPSEEL椭圆斜看过去的圆管口、示意性设备
HATCHH图案填充（剖面线）剖面图里填混凝土、填土、保温层

XLINEXL两端无限长的构造线当辅助线用，画完删掉。定位中心线、对齐基准
MLINEML多条平行线画双线墙体、双线道路
DONUTDO圆环（实心圈）画粗点、节点标记、管道断点

RAY—一端无限长的射线辅助线，用得比构造线少

快捷键按 Autodesk 官方《AutoCAD 快捷键手册》与 AutoCAD 2018 中文版界面。RAY（射线）没有默认快捷键，要在命令行打全名。

图 02

命令框实况：每个命令到底在跟你说什么

绿字=你输入的，橙字=可以选的选项
先学会看命令行：命令: 后面是你敲的；方括号 [ ] 里的字母是可以选的选项，敲那个字母回车就切换；尖括号 < > 里是默认值，直接回车就用它。
L直线LINE
命令行
命令: L
LINE 指定第一点: （点起点）
指定下一点或 [放弃(U)]: （点第二点）
指定下一点或 [放弃(U)]: （点第三点）
指定下一点或 [闭合(C)/放弃(U)]: C
U = 撤掉刚画的那一段；C = 自动连回起点，画闭合图形用它收尾。
PL多段线PLINE
命令行
命令: PL
PLINE 指定起点: （点一下）
当前线宽为 0.0000
指定下一个点或 [圆弧(A)/半宽(H)/长度(L)/放弃(U)/宽度(W)]: W
指定起点宽度 <0.0000>: 0.5
指定端点宽度 <0.5000>: 回车
W 是设线宽（画粗管线、箭头全靠它）；A 切到画圆弧；U 撤一段。首尾宽度不一样就是箭头。
C圆CIRCLE
命令行
命令: C
CIRCLE 指定圆的圆心或 [三点(3P)/两点(2P)/切点、切点、半径(T)]: （点圆心）
指定圆的半径或 [直径(D)]: D
指定圆的直径: 8000
直接输数字 = 半径；先敲 D 再输数字 = 直径。图纸标的是 Ø8000 就用 D，别自己除以 2。
A圆弧ARC
命令行
命令: A
ARC 指定圆弧的起点或 [圆心(C)]: （点起点）
指定圆弧的第二个点或 [圆心(C)/端点(E)]: E
指定圆弧的端点: （点端点）
指定圆弧的圆心或 [角度(A)/方向(D)/半径(R)]: R
指定圆弧的半径: 1500
默认是「三点画弧」。敲 C 就是先定圆心再画，画管道弯头顺手得多。
REC矩形RECTANG
命令行
命令: REC
指定第一个角点或 [倒角(C)/标高(E)/圆角(F)/厚度(T)/宽度(W)]: F
指定矩形的圆角半径 <0.0000>: 200
指定第一个角点: （点一下）
指定另一个角点或 [面积(A)/尺寸(D)/旋转(R)]: D
指定矩形的长度 <10.0000>: 5000
指定矩形的宽度 <10.0000>: 3000
先敲 F 给圆角 → 画出来直接是圆角矩形；敲 D 直接输长宽，不用数格子。
POL正多边形POLYGON
命令行
命令: POL
POLYGON 输入边的数目 <4>: 6
指定正多边形的中心点或 [边(E)]: （点中心）
输入选项 [内接于圆(I)/外切于圆(C)] <I>: C
指定圆的半径: 20
I = 顶点落在圆上；C = 边贴着圆。已知「对边距离」（如六角螺栓）选 C。
EL椭圆ELLIPSE
命令行
命令: EL
ELLIPSE 指定椭圆的轴端点或 [圆弧(A)/中心点(C)]: （点一端）
指定轴的另一个端点: （点另一端）
指定另一条半轴长度或 [旋转(R)]: 800
先定长轴两头，再给短轴的一半长度。注意是半轴，不是全长。
H图案填充HATCH
命令行
命令: H
（弹出「图案填充和渐变色」对话框）
选图案 → 设比例 → 点「添加：拾取点」
拾取内部点或 [选择对象(S)/删除边界(B)]: （在闭合区域里点一下）
回车 → 确定
区域必须严丝合缝闭合，有一条缝就会报「边界未闭合」，这是填充失败的头号原因。
XL构造线XLINE
命令行
命令: XL
XLINE 指定点或 [水平(H)/垂直(V)/角度(A)/二等分(B)/偏移(O)]: H
指定通过点: （点一下）
指定通过点: （再点一下，或回车结束）
两端无限长的辅助线。用完记得删掉（E），不然打印时会满纸都是。
SPL样条曲线SPLINE
命令行
命令: SPL
SPLINE 当前设置: 方式=拟合 节点=弦
指定第一个点或 [方式(M)/节点(K)/对象(O)]: （点起点）
指定下一点: （连着点几个点）
指定下一点或 [端点相切(T)/公差(L)/放弃(U)]: 回车
点几个点位，软件自动穿成光滑曲线。画等高线、水面线、不规则边界。
DO圆环DONUT
命令行
命令: DO
DONUT 指定圆环的内径 <0.5000>: 0
指定圆环的外径 <1.0000>: 300
指定圆环的中心点或 <退出>: （点一下）
指定圆环的中心点或 <退出>: 回车
内径填 0 = 实心圆点。可以做节点标记、粗点。
ML多线MLINE
命令行
命令: ML
MLINE 当前设置: 对正 = 上，比例 = 20.00，样式 = STANDARD
指定起点或 [对正(J)/比例(S)/样式(ST)]: S
输入多线比例 <20.00>: 240
指定起点: （点一下）
比例就是两条平行线的间距，画 240 墙就输 240。J 决定你点的位置是墙的哪一边。
DIV定数等分DIVIDE
命令行
命令: DIV
DIVIDE 选择要定数等分的对象: （选那条线）
输入线段数目或 [块(B)]: 8
输 8 = 均分成 8 段，落下 7 个点（点比分线段数少一个）。敲 B 可以把「点」换成「图块」。
ME定距等分MEASURE
命令行
命令: ME
MEASURE 选择要定距等分的对象: （选那条线）
指定线段长度或 [块(B)]: 30000
每隔 30000（30 米）放一个。最后不够一段就不放，所以点数跟总长有关。
等分出来的点看不见？默认点样式就一个小点，几乎找不着。先输 DDPTYPE（点样式）换个十字或圆点，再等分就能看见了。
图 03

最容易搞混的一对：直线 vs 多段线

选错就白画
L直线 LINE

每一段都是单独的对象。点一下只选中一根，偏移要一根一根来，算面积算不出来。

PL多段线 PLINE

整条是一个对象。一次偏移就整体挪，能直接算周长和面积，能整体改线宽。

什么时候必须用 PL：画工艺管线的走向箭头（要粗线宽）、画要填图案的闭合区域、画完要算面积的池体轮廓。
已经用 L 画错了怎么办：输入 PE（PEDIT 多段线编辑） → 选其中一根 → 输入 J（合并）→ 框选全部 → 回车，就能把散线接成一条多段线。
图 04

圆的六种画法

环境工程画圆形池子必会
圆心 + 半径
已知圆心位置和半径。默认方式，最常用
C → 点圆心 → 输半径
圆心 + 直径
图纸标的是直径时用（比如池内径 Ø8000）
C → 点圆心 → 输 D → 输直径
两点
两点当直径的两端。用在「这段就是直径」的时候
C → 输 2P → 点两头
三点
圆过三个已知点。定圆心麻烦时用它
C → 输 3P → 点三点
相切 + 相切 + 半径
圆要同时贴着两条线（或圆），给定半径。画管道弯头、池体切角
C → 输 T → 选两条 → 输半径
相切 + 相切 + 相切
圆卡在三个对象中间，半径不用给，软件算
C → 输 3P → 再输 T → 逐个选
画圆形沉淀池平面：一般用「圆心 + 直径」，因为图纸上标的都是 Ø（直径）。输入 C → 点池中心 → 输 D → 输 8000 → 回车，一个内径 8 米的池子圆就出来了。
图 05

矩形 与 正多边形

内接还是外切，别选反
REC矩形 RECTANG

整体对象（本质是闭合多段线）：能直接偏移、倒角、圆角、算面积。画池体矩形平面、设备基础都用它，别用 L 画四根线。

POL正多边形 POLYGON

输边数（3~1024）→ 点中心 → 选「内接于圆 I」还是「外切于圆 C」→ 给半径。

六角螺栓头要的是「对边距离」= 外切圆直径，选 C（外切）；才知道外接圆大小时选 I（内接）。
图 06

定数等分 与 定距等分

名字像，干的活不一样
DIV定数等分 DIVIDE

你告诉它「分成 6 段」，它就把这条线均匀切成 6 份，落下 5 个点。每段多长它自己算。

例：格栅渠要均布 8 根栅条 → DIV → 选渠边线 → 输 8
ME定距等分 MEASURE

你告诉它「每隔 2000 放一个」，它就按这个间距摆点。最后不够一段的，就不放。

例：管线每 30 米一个检查井 → ME → 选管线 → 输 30000
等分出来的点看不见？默认的点样式就一个小点，几乎找不着。先输 DDPTYPE（点样式）换个十字或圆点样式，再等分就能看见了。

串一遍：画一个圆形沉淀池平面

把命令连起来用
STEP 1
画池壁外圈
圆心 + 直径，输内径 8000
C → D
STEP 2
偏移出壁厚
向外偏 240（池壁厚），同心圆
O 偏移
STEP 3
画中心筒
再画一个小圆，直径 1500
C
STEP 4
画走道板分格
把外圈按 8 段等分落点
DIV
STEP 5
填混凝土剖面

关键顺序：先画主体圆，再偏移出壁厚（比画两个同心圆快得多），最后填充。很多人习惯先画两个圆再算差，多一步还容易错。
