一句话讲透：块到底解决什么问题

WHOLE OBJECT, ONE DEFINITION

块（Block）是把若干线条、文字、填充打包成一个整体对象。图形里只存一份“块定义”，其余地方全是“块参照”——像同一个母版印出来的许多张，改母版，全部跟着变。

体积小

重复图形只存一次定义，几十个门、上百个轴号也不明显撑大文件。

插入快

选一次、点一下，比框选复制少一半操作；还能带基点精准落位。

改一处全改

重定义块后，图内所有参照同步更新，不会漏改某一扇门。

六种“块”，先分清再动手

DON'T MIX THEM UP

新手最容易混的是“内部块 / 外部块 / 属性块 / 动态块”——它们不是并列的四种东西，而是按“存在哪”和“带不带数据”两个维度交叉出来的。先看这张表。

类型命令存在哪里典型用途
内部块（临时块）B / BLOCK只存在当前 DWG 里，换文件就没有本图专用的门、窗、轴号、图框
外部块（写块）W / WBLOCK单独存成 .dwg 文件，可跨图纸调用企业图库、标准图例、重复使用的图框
插入块I / INSERT不产生新块，只是“摆放”已有块把上面两种放到图中
属性块ATT + B块内嵌可填写的文字字段轴号、门窗编号、标高、图签栏
动态块BE / BEDIT块内带参数与动作，可拉伸/翻转/切换一扇门搞定 750/900/1000 三种宽度
外部参照（不是块）XR / XREF引用别的 dwg 文件，本体不在本图建筑底图套结构图，底图改了自动跟着变

记忆法：B 是“存进本图”，W 是“存成文件”，I 是“拿出来摆”，ATT 是“给它装个输入框”。

块与外部参照，一句话区分
块 = 影印件

内容已经印进本图。源文件改了，本图不会自动变，得重新插入覆盖。适合小对象、图例。

外部参照 = 玻璃窗

只是“看向”另一个文件。对方一存盘，本图重开就同步。适合整张底图，且不会把对方内容吞进本图。

THE WHOLE LOOP

无论是做一个门、一个轴号还是一整张图框，走的都是这 6 步。其中第 2 步（定属性）只有需要填不同文字时才做，其余五步是通用主线。

图 2　六步主线 + 一条回流（改块定义）

铁律一 · 画在 0 层

块内几何放在 0 层、颜色随层，插到哪层就显哪层颜色。否则插进灰色图层它还是黄的。

铁律二 · 基点选功能点

基点是插入时“捏住”的那个点：门轴、圆心、图框右下角。选在图形外，每次插都要挪。

铁律三 · 改定义不炸开

要改就 BEDIT 改定义，全图同步；炸开只改一个，等于断了与母版的联系。

建内部块：B 块定义对话框逐项拆解

BLOCK · 7.1.1.1

三种启动方式，任选：命令行 B 绘图 → 块 → 创建 功能区 插入 → 块定义 → 创建块。

图 3　块定义对话框（对应教材 图 7-1）

三个“对象”选项，到底选哪个
选项定义后原图形什么时候用
保留原样留在图上，另生成一个块定义原图形还要单独用；或准备做“块 + 参照”两套
转换为块（默认推荐）就地变成块参照99% 的情况。图形直接成了可重复调用的块
删除从图中清掉，只留块定义只想入库、暂不摆放
名称与基点：两条能省下大量返工的习惯

命名用“类别-规格”三段式：DOOR-900、WIN-C1518、GRID-A、TB-A3。中文名虽然合法，但跨版本、跨插件、脚本调用时容易出问题；中英混排还容易多打空格——空格是合法的，但会让后续查找很痛苦。

基点就选“功能定位点”：

门 / 窗

门放门轴，窗放洞口边中点。插入时直接点洞口端点，不用再移。

轴号 / 标高

放圆心或符号尖端，正好落在轴网交点、标高线上。

图框 / 图签

放内框右下角，与图纸边界对齐，套图时一键落位。

家具 / 设备

放靠墙面中点或中心，方便贴墙、居中布置。

写块：W 把块变成能带走的 .dwg

WBLOCK · 7.1.1.2

WBLOCK 的本质是“另存一个只含这块图形的 dwg 文件”。它既是“存块”，也是“把当前图形的一部分单独导出”的利器。命令：W WBLOCK。

图 4　写块对话框（对应教材 图 7-3）

“源”的三个选项怎么选
源含义典型场景
块把图中已有块定义原样导出为新文件整理图库：把本图攒下的块逐个 W 出去
整个图形整张模型空间存成一个 dwg（含未使用的块定义）拆图、导出单张平面、做“底图”
对象临时框选一部分图形，存成文件从大图里抠一个节点详图/一个符号
和“另存为 / 导出”的区别

另存为会把整张图连同布局、图层、标注样式一起带走；W 只带走“这一个对象 + 它必需的图层/线型/文字样式”，文件往往只有几十 KB。做图库用 W，做备份用另存为。

插入块：I 定点、定比例、定角度

INSERT · 7.1.2

图 5　插入对话框（对应教材 图 7-4）

三个比例技巧，绝大多数教程没讲
负数 = 镜像

比例填 -1 得到左右镜像的块，X=-1 Y=1 水平翻，X=1 Y=-1 垂直翻。比先插入再 MIRROR 快。

非等比 = 变形

X=1、Y=0.5 会把块压扁。只有图例符号（如阀门、箭头）可以这么干；门、家具千万别。

命令行更快

插入后不回对话框，直接敲 S 改比例、R 改角度、B 换基点，连点带敲一气呵成。

重复插入：别一遍遍点

插入对话框底部有“重复放置”，勾上后可连点多个位置；老版本可在插入后直接按回车重复上一个命令。要按规律排（柱、灯具、轴线号），用 ARRAY（阵列）选“块参照”最快，改一个全排跟着变。

属性块：让同一个块“每处写不同字”

ATTDEF · EATTEDIT · 7.2

普通块里的文字是死的——十个轴号插进去全是“A”。属性（Attribute）是块里的“可填写字段”：几何一样，每次插入可以填不同值，之后还能改、能被统计。

标记 Tag

字段的“内部名”，相当于数据库列名。不能有空格，字母会自动转大写。如 NUM、DWG_NO。

提示 Prompt

插入时问你的那句话，给人看的。如“请输入轴号”。留空则直接用标记当提示。

默认值 Value

不填时用什么。常填最常见的规格，如 900、A，能省大量回车。

改块三把刀：改定义、在位改、同名重定义

BEDIT / REFEDIT / REDEFINE

块做好后总要改。三种方式影响范围不同，选错会把图改乱：

方式命令 / 入口影响范围适合
块编辑器（首选）BE / BEDIT，或右键块 → 块编辑器改定义，全图所有参照同步更新统一改尺寸、加线条、加属性、做动态块
在位编辑REFEDIT，或右键 → 在位编辑块也在改定义，但能看到周边图形作参照改的时候需要对齐旁边的墙、轴线
同名重定义画好新图形 → B → 输入已有块名覆盖原定义，全图更新块要整体换掉、旧定义已乱
顺带把动态块做了：BE

动态块 = 块 + 参数（夹点）+ 动作（夹点拉动时发生什么）。最小可用案例，做一扇能调宽、能左右翻的门：

  1. 先有普通块

    画门（门扇 + 开启弧），B 定义成 DOOR-900，基点放门轴。

  2. 进块编辑器

    双击块，或 BE 选该块。界面变灰，出现“块编写选项板”。

  3. 加线性参数

    选项板 → 参数 → 线性，从门轴拉到门扇外沿，命名为“门宽”。

  4. 加拉伸动作

    选项板 → 动作 → 拉伸，选“门宽”参数 → 选参数点 → 框住门扇右端 → 回车。此时拉夹点，门扇会跟着变长。

  5. 加翻转参数

    参数 → 翻转，沿门扇中线放一条翻转轴；动作 → 翻转，选该参数 → 框选全部门图形。

  6. 限定可选宽度（可选）

    选中“门宽”参数 → 特性面板 → 值集 → 列表，填入 750 / 900 / 1000，夹点就只能停在这三档。

  7. 测试并保存

    点“测试块”试拉、试翻；没问题后“关闭块编辑器”→ 保存更改，全图该块立即获得夹点。

图 10

实战：10 分钟做一个“轴号”属性块

WALKTHROUGH · 圆 + 属性 → 块 → 插入 → 改值

选它是因为它把“画几何 → 定属性 → 建块 → 插入 → 编辑属性”整条链走了一遍，而且出图立刻能用。假设 1:100 出图，圆直径 800，字高 500。

  1. 画圆

    在 0 层画 C 圆，直径 800。若要双线圈，再 O 偏移 100。

  2. 定属性

    ATT → 标记 NUM、提示“请输入轴号”、默认 A；对正选正中，字高 500；插入点点圆心。

  3. 检查

    图上应出现一个 NUM 字样（这就是属性定义本体，尚未成为块的一部分）。

  4. 建块

    B → 名称 GRID-A → 拾取基点＝圆心 → 框选“圆 + NUM” → 选“转换为块” → 确定。

  5. 插入

    I → 选 GRID-A → 勾“在屏幕上指定” → 在轴网端点点击 → 命令行提示“请输入轴号 <A>:”，输入 1。

  6. 继续排

    同一命令连点其余轴线端点，依次填 2、3、4；竖向用 I 后 R 旋转 90°，或插入后夹点旋转。

  7. 改值

    填错了？双击该轴号 → 属性选项卡 → 值改为 B → 确定。只影响这一处，其他轴号不动。

  8. 入库

    W → 源选“块” → 选 GRID-A → 存成 D:\图库\GRID-A.dwg，单位毫米。以后任何图纸 I → 浏览即可用。

  9. 出表（可选）

    DATAEXTRACTION → 选本图 → 勾 GRID-A 与 NUM → 输出表格，得到“轴号清单”，改图后重跑一次即可更新。

#现象真正原因解法
1块插到某图层后，颜色不跟着图层变块内对象被设成了具体图层/具体颜色，而不是 0 层 + ByLayer进 BE，把块内几何全部改到 0 层、颜色 ByBlock/ByLayer；批量可用 SETBYLAYER
2块插进来特别大或特别小（差 25.4 倍）源图与目标图 INSUNITS 不一致（英寸 vs 毫米）两边都设 INSUNITS=4；已插入的用 SCALE 按 25.4 或 1/25.4 修正
3给块加了新属性，旧的地方不显示旧参照还停在旧定义ATTSYNC → 选该块名 → 是；或 BATTMAN 里“同步”
4插入属性块不弹输入提示，直接落默认值ATTREQ=0 或属性被设成了“固定/预设”ATTREQ 设 1；检查属性模式
5块改不动、夹点拉不动、炸不开块被设为“不允许分解”，或图层被锁定/冻结Ctrl+1 看“允许分解”；解冻解锁图层
6块名删不掉，PU 也清不掉图里还有参照（可能藏在别的块里，或被冻结图层上）用 QSELECT/COUNT 找全，删净后再 PU（可试 -PURGE → 块）
7炸开后属性文字变成普通文字，改不了值炸开即脱离定义，属性退化为 ATTDEF/TEXT撤销；改用 BEDIT 改定义，或用 EATTEDIT 改值
8本图块明明改了，同事的图打开还是旧样块不跨文件同步，外部块文件也没重新导出重新 W 覆盖图库文件；对方插入时选“重定义”

图 8　四级叠加：从普通块一路升到动态属性块

每升一级都是加一层能力，不是换一种块：只在本图用，可以停在 ②；不需要填字，跳过 ④；尺寸固定，跳过 ⑤。任意组合都成立。唯一不该做的，是为了“就改这一处”把块炸开——那等于退回复制粘贴，统计和联动全部失效。

记住这一句

块的本质是用一个定义管住许多实例。凡是要重复、要统一、要统计的图形，都该做成块。

记住这一条

要改就改定义，不要炸开改单个。炸开等于退回到“复制粘贴”。

记住这一步

做好的块一定 W 出去存档。只存在图里的块，换台电脑就等于没做过。
