图 02

命令框实况：每个命令到底在跟你说什么

绿字=你输入的，橙字=可以选的选项
先学会看命令行：命令: 后面是你敲的；方括号 [ ] 里的字母是可以选的选项，敲那个字母回车就切换；尖括号 < > 里是默认值，直接回车就用它。所有修改命令都是「先选对象，回车，再操作」。
O偏移OFFSET
命令行
命令: O
OFFSET 当前设置: 删除源对象=否 图层=源
指定偏移距离或 [通过(T)/删除(E)/图层(L)] <通过>: 240
选择要偏移的对象，或 [退出(E)/放弃(U)] <退出>: （选池壁圆）
指定要偏移的那一侧上的点，或 [退出(E)/多个(M)/放弃(U)] <退出>: （点外侧）
三步走：输距离 → 选对象 → 点偏哪一侧。敲 T 可以让偏移后的线刚好通过某个点（不用算距离）。
TR修剪TRIM
命令行
命令: TR
TRIM 当前设置: 投影=UCS，边=无
选择剪切边... 选择对象或 <全部选择>: 回车
选择要修剪的对象，或按住 Shift 键选择要延伸的对象，或 [栏选(F)/窗交(C)/投影(P)/边(E)/删除(R)/放弃(U)]:
（点要剪掉的线头）
直接回车 = 全图都当剪刀，然后点哪剪哪，省掉选边界这步。这是最省事的用法。
EX延伸EXTEND
命令行
命令: EX
EXTEND 当前设置: 投影=UCS，边=无
选择边界的边... 选择对象或 <全部选择>: 回车
选择要延伸的对象，或按住 Shift 键选择要修剪的对象，或 [栏选(F)/窗交(C)/投影(P)/边(E)/放弃(U)]:
（点要补长的线）
操作步骤跟修剪一模一样。按住 Shift 能临时切成修剪，两个命令来回切。
F圆角FILLET
命令行
命令: F
FILLET 当前设置: 模式 = 修剪，半径 = 0.0000
选择第一个对象或 [放弃(U)/多段线(P)/半径(R)/修剪(T)/多个(M)]: R
指定圆角半径 <0.0000>: 30
选择第一个对象或 [...]: （点第一条线）
选择第二个对象，或按住 Shift 键选择要应用角点的对象: （点第二条）
第一次必须先敲 R 设半径，否则半径是 0，倒出来什么都没有。M = 连着倒多个角不退出。
CHA倒角CHAMFER
命令行
命令: CHA
CHAMFER 选择第一条直线或 [放弃(U)/多段线(P)/距离(D)/角度(A)/修剪(T)/方式(E)/多个(M)]: D
指定第一个倒角距离 <0.0000>: 40
指定第二个倒角距离 <40.0000>: 回车
选择第一条直线: （点第一条）
选择第二条直线: （点第二条）
两个距离相等就是标准 45° 倒角。第二个距离默认跟着第一个，直接回车即可。
CO复制COPY
命令行
命令: CO
COPY 选择对象: 找到 1 个
选择对象: 回车
指定基点或 [位移(D)/模式(O)] <位移>: （在对象上点个基准点）
指定第二个点或 [阵列(A)] <使用第一个点作为位移>: @12000,0
@12000,0 = 相对刚才那个点向右 12000。@ 符号就是「相对」的意思，画第二格池子直接用。
MI镜像MIRROR
命令行
命令: MI
MIRROR 选择对象: 找到 1 个
指定镜像线的第一点: （点对称轴一头）
指定镜像线的第二点: （点另一头）
要删除源对象吗？[是(Y)/否(N)] <否>: N
N = 原来的留着（两边都有）；Y = 原来的删掉（相当于翻过去）。文字会被镜像反，先输 MIRRTEXT 设成 0。
AR阵列ARRAY
命令行
命令: AR
ARRAY 选择对象: 找到 1 个
输入阵列类型 [矩形(R)/路径(PA)/极轴(PO)] <矩形>: PO
指定阵列的中心点或 [基点(B)/旋转轴(A)]: （点池中心）
输入阵列中的项目数目: 8
指定填充角度 (+=逆时针, -=顺时针) <360>: 回车
R 排行列、PA 沿线排、PO 绕圈排（界面里叫「环形阵列」）。填 360 回车 = 整整一圈。
M移动MOVE
命令行
命令: M
MOVE 选择对象: 找到 1 个
指定基点或 [位移(D)] <位移>: （在自己身上点个"把手"）
指定第二个点或 <使用第一个点作为位移>: （把手放到目标位置）
先在自己身上抓一个点，再把这个点放到目标处。开对象捕捉（F3）抓端点、中点最准。
RO旋转ROTATE
命令行
命令: RO
ROTATE 指定基点: （点旋转中心）
指定旋转角度，或 [复制(C)/参照(R)] <0>: 90
正角度 = 逆时针，负角度 = 顺时针。C = 转一份、原样留一份；R = 照着现有方向对齐（改管线走向时超好用）。
SC缩放SCALE
命令行
命令: SC
SCALE 选择对象: 找到 1 个
指定基点: （点一个不动的点）
指定比例因子或 [复制(C)/参照(R)] <1.0000>: R
指定参照长度 <1>: （点现在的长度两端）
指定新的长度或 [点(P)] <1>: 5000
直接输 2 = 放大一倍，0.5 = 缩小一半。敲 R 可以输「现在多长 → 应该多长」，不用自己算比例。
S拉伸STRETCH
命令行
命令: S
STRETCH 以交叉窗口或交叉多边形选择要拉伸的对象...
选择对象: 指定对角点: （从右往左拉框，虚线框）
选择对象: 回车
指定基点或 [位移(D)] <位移>: （点一下）
指定第二个点或 <使用第一个点作为位移>: （往要拉的方向点）
命令行第一句就明说了：必须交叉窗口（从右往左拉）。拉成实线框就变成移动了。
BR打断BREAK
命令行
命令: BR
BREAK 选择对象: （点对象，这一点就是第一个断点）
指定第二个打断点 或 [第一点(F)]: （点第二点）
两点之间那段被挖掉。想精确指定第一个断点就敲 F，不然「点对象」的那下也算断点，位置不准。
J合并JOIN
命令行
命令: J
JOIN 选择源对象或要一次合并的多个对象: （框选要接的几段）
选择要合并的对象: 回车
3 条直线已合并为 1 条直线
前提是在同一条直线上（共线），歪一点都合不了。合完就变成整体，能一起偏移。
X分解EXPLODE
命令行
命令: X
EXPLODE 选择对象: 找到 1 个
选择对象: 回车
（图块 / 矩形 / 多段线 被拆成单独的线和弧）
炸开是不可逆的整体感：炸完就不能整体偏移、整体改线宽了。要改整体前先想清楚。
LEN拉长LENGTHEN
命令行
命令: LEN
LENGTHEN 选择对象或 [增量(DE)/百分数(P)/全部(T)/动态(DY)]: DY
选择要修改的对象或 [放弃(U)]: （点线靠近要长的那一端）
指定新端点: （拖到想要的长度）
DY（动态）最直观：点哪一端就拖哪一端。DE = 输「加长多少」，T = 输「改成总共多长」。
E删除ERASE
命令行
命令: E
ERASE 选择对象: 找到 1 个
选择对象: 回车
（对象消失）
跟「先选中、再按键盘 Delete 键」效果一样。删错了按 Ctrl+Z 撤回来。

三个「都是复制」的命令，别混

新人第一道坎
CO复制 COPY

原样搬一份到别处，方向、大小完全不变。你给个方向和距离就行。

例：一号池画好了，二号池一模一样 → CO，指定间距 12000
MI镜像 MIRROR

沿一条对称轴翻面复制。形状镜像对称，左右颠倒。

文字会被镜像反！命令行问「是否删除源对象」之前，先把 MIRRTEXT 系统变量设成 0，文字才不会变成反的。
O偏移 OFFSET

生成一个等距的新对象。圆→同心圆，直线→平行线，多段线→整体平行。

例：池内壁画好了，壁厚 240 → O，输 240，点外侧
图 04

修剪 与 延伸：一对反操作

先选边界，再选对象
TR修剪 TRIM —— 剪短的

把线超出去的部分剪掉。操作：TR 回车 → 先点边界线（竖线）→ 回车 → 再点要剪掉的那一段。

嫌选边界麻烦？TR 回车后直接再回车一次，等于「全图都能当边界」，然后直接点要剪的线头，快很多。
EX延伸 EXTEND —— 补长的

把线补长到边界上。操作跟修剪一模一样：EX 回车 → 先点边界 → 回车 → 点要延长的线。

同样可以 EX 回车后再回车，跳过选边界这步。
记法：两个命令的操作顺序完全一样 —— 都是「先选边界，回车，再选对象」。区别只在于一个是剪短、一个是补长。按住 Shift 还能在两个命令之间临时切换。
图 05

移动 与 拉伸：一个整体搬，一个局部拽

拉伸必须「交叉框选」
M移动 MOVE

整个对象原封不动换个位置。形状、大小都不变。

S拉伸 STRETCH

只把被框住的那一头拽走，没框住的那头钉着不动，形状跟着变。

必须用「交叉框选」：鼠标从右往左拉，框成虚线绿框。从左往右拉（实线蓝框）会把整个对象选中，就变成移动了。
框选方向是新人最常踩的坑：从左往右拉 = 实线框 = 只有完全框住的才选中；从右往左拉 = 虚线框 = 碰到就选中。拉伸、延伸、修剪这些「只改一部分」的命令，都用后者。
图 06

圆角 与 倒角

一个圆滑，一个切平
F圆角 FILLET

两条线之间用圆弧过渡，给半径 R。操作：F → 输 R → 输半径值 → 点两条线。

池体内壁转角、管线转弯都用这个。半径设 0 时，能当「把两条线接到一起」用。
CHA倒角 CHAMFER

把尖角切掉一小块，成一个斜面。给两个距离（或距离+角度）。操作：CHA → 输 D → 输两个距离 → 点两条线。

设备基础、安装孔的 45° 倒角。两个距离相等就是标准 45° 倒角。
图 07

阵列的三种排法

批量布置设备全靠它
矩形阵列
排成几行几列。给行数、列数、行距、列距
AR → 矩形(R)
例：曝气池底 4×3 个曝气头
路径阵列
沿着一条线（路径）等距排布
AR → 路径(PA)
例：沿管沟每 30m 一个检查井
环形阵列
绕一个中心点转圈排。给数量、总角度
AR → 环(PO)
例：圆形池子一圈 8 个布水口
三种阵列关系：阵列出来的对象是一组，改一个全跟着改（阵列是关联的）。要单独改某一个，先输 X（分解） 把它炸开。
图 08

框选方向：决定你选中了什么

所有修改命令的第一步
←→从左往右拉 = 窗口选择

框是实线。对象必须整个在框里面才算选中。碰边不算。

→←从右往左拉 = 交叉选择

框是虚线。只要碰到框就算选中，不用整个进去。

什么时候用哪个：要整个对象（复制、移动、删除）→ 从左往右，实线框。只要改一部分（拉伸、局部修剪）→ 从右往左，虚线框。
记不住就看框的颜色：蓝实线 = 全包住，绿虚线 = 碰就中。
